# miguelpitarch.com

Personal portfolio of Miguel Pitarch, freelance software developer & designer.

Static site: plain HTML, CSS and JavaScript with [GSAP](https://gsap.com) + ScrollTrigger and [Lenis](https://lenis.darkroom.engineering) for smooth scrolling. No build step.

## Run locally

```bash
python3 -m http.server 5173
```

Then open http://localhost:5173.

## Font

The design uses **PP Neue Montreal** (free for personal use at pangrampangram.com). Put `PPNeueMontreal-Book.woff2`, `PPNeueMontreal-Thin.woff2` and `PPNeueMontreal-Bold.woff2` in `fonts/`. Without them the site falls back to Inter Tight.
